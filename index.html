GoToFile

A fast, flexible utility for fuzzy and RegEx file search on macOS. Access any file or folder precisely, beyond Spotlight's limits.

Precise Fuzzy Search

Find files by name or path with intelligent fuzzy matching or regular expressions. Results appear instantly from tens of thousands of files, powered by an in-memory index.

Custom Search Sets

Define focused search locations on the fly. Narrow to projects, drives, or directories without rebuilding indexes—perfect for targeted workflows.

Seamless File Actions

Open in default apps, current editor, or type paths directly (ideal for Terminal). Copy, move, rename, duplicate, drag-and-drop, and QuickLook previews—all in one place.

Replaces Open Dialogs

Skip macOS file dialogs entirely. Launch files effortlessly, replacing slow browsing with instant, accurate access.

Lightweight Performance

Searches only by name and path for speed. No heavy metadata reliance unless needed. Version 1.32.1 includes refined sorting, localized numbers, and project cache details.

How It Works

1. Activate Search

Invoke GoToFile with a global shortcut. It launches instantly, ready to query your entire Mac or custom sets.

2. Type to Find

Enter fuzzy queries or RegEx patterns. See ranked results update in real-time as you type—no delay.

3. Act Instantly

Arrow to select, then open, copy path, drag, or manage files. QuickLook previews on demand.

4. Refine and Repeat

Switch search sets, toggle filters, or sort by path, name, or extension. Workflow adapts to you.

FAQ

Does it replace Spotlight?

No—GoToFile complements it with fuzzy/RegEx precision and custom scopes Spotlight can't match.

Is it fast on large drives?

Yes. In-memory indexing delivers results from massive libraries before you finish typing.

Can I search specific projects?

Absolutely. Define search sets for folders, volumes, or paths on demand.

What about file management?

Full support: open, copy/move/rename/duplicate paths, drag-and-drop, QuickLook.
